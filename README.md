# 📘 Vocabulary & Key Ideas  

## 🌐 General  
- **LLM (Large Language Model):** An AI model trained on vast amounts of text/code that can generate, understand, and interact in natural language.  
- **Prompt:** The instructions or request you give the AI. Clear prompts = better results.  
- **Prompt Engineering:** The craft of shaping prompts to guide AI toward the desired output.  
- **Context Window:** The memory span of the AI in a session; limits how much it can “remember” at once.  

---

## 🎵 Vibe Coding Terms  
- **Vibe Coding:** A programming paradigm where you describe what you want in plain language, and the AI generates the code.  
- **The “Vibe”:** The intent or desired outcome you communicate instead of precise syntax.  
- **Conversational Coding:** Iterative back-and-forth with the AI to refine outputs.  
- **Role Shift:** Developers move from coders → to directors, editors, and testers.  
- **Flow State:** Many users describe vibe coding as joyful, staying “in flow” without syntax distractions.  
- **Prompt Spirals:** Frustrating loops where the AI gets confused and repeats mistakes; solved with clearer instructions.  
- **Impressionistic Scanning:** Quickly reviewing AI code for patterns/structure instead of line-by-line reading.  

---

## 🤖 Agentic Coding Terms  
- **Agentic AI:** AI systems that act autonomously, planning and executing tasks toward goals with less human input.  
- **Agentic Coding:** Applying agentic AI to software development — the AI becomes a peer programmer that can plan, build, test, and debug.  
- **Delegated Autonomy:** Developers set goals, AI agents execute plans independently.  
- **Reason/Plan/Act/Refine Loop:** The iterative cycle of perceiving environment → reasoning → acting → observing → refining.  
- **Task Decomposition:** Agents break down a big goal (like “build an API”) into smaller tasks (routes, database models, tests).  
- **Multi-File Editing:** Ability of an agent to change several files at once (refactor, restructure, add dependencies).  
- **Sandboxed Execution:** Running agent code in safe, isolated environments to prevent security risks.  
- **Pull Request Review:** Common workflow where the AI proposes changes, but humans still review/merge.  

---

## ⚖️ Cross-Cutting Ideas  
- **Accessibility:** Both paradigms lower barriers, letting beginners code through natural language.  
- **Risk of Skill Atrophy:** Over-reliance on AI can weaken core coding fundamentals.  
- **Security Risks:** AI may generate vulnerable code or leak secrets if unchecked.  
- **Architect Mindset:** The future developer role = less about typing code, more about designing systems, setting constraints, and reviewing outcomes.  
- **Community Learning:** These tools are most powerful when paired with mentorship and collaborative practice.
